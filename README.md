# 📝 VoxiHost Blog Content

This repository contains the source Markdown files, images, and compiled ZIP packages for all VoxiHost blog posts and guides. It is designed to be contributor-friendly, allowing the community to submit edits, fixes, and guest posts directly.

---

## 📥 Getting Started

This repository contains only **Markdown source files and images**. You don't need to install anything or run any commands to contribute.

### ✍️ For Everyone (External Contributors & Community)
1. Edit or add raw Markdown files and images under the `src/` directory (`src/published/` for edits, `src/drafts/` for new articles).
2. You can do this directly using the **GitHub Web Interface** (no cloning needed) or by cloning the repo locally.
3. Once your PR is approved and merged, the VoxiHost team handles the rest — compiling ZIP packages and deploying to the live blog.

> [!NOTE]
> You will never need to touch `dist/`, run scripts, or install Node.js. Those are internal team operations managed outside this repository.
